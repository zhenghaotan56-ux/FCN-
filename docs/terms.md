# 产品条款与接口

首版模板 `fcn-3m-fixed-v1` 支持股票所在市场币种 HKD 或 USD。固定三个月，按面值认购，存续期无条件固定计息，终止时一次付息，计息基准 ACT/365F。估值日取最近一个完整收盘或客户选定的历史交易日，样板的起息日使用该日。

| 条件 | 本金现金流 | 票息 |
| --- | --- | --- |
| 第一或第二个月观察价达到敲出价 | 返还面值，首次命中即终止 | 计息到该观察日 |
| 未提前终止，最终观察价达到接货价 | 到期返还面值 | 计息到最终观察日 |
| 未提前终止，最终观察价低于接货价 | 股数等值为面值除以接货价，估值采用最终观察价计量 | 计息到最终观察日 |

到期价恰好等于接货价时还本。敲出价高于接货价，第三个月最终观察只结算一次。无敲出仅生成最终观察日。日期按起息日的月度对应日生成，月末取该月最后一日，遇非交易日顺延。样板中观察、付息和交割同日，系统分别存储日期。客户版采用确认后的发行条款，需复核顺延、结算延迟、币种日历和零碎股规则。

接货价及敲出价可按参考价比例或绝对价输入，样板按两位小数四舍五入。接货价大于零且不高于参考价。面值支持 100 至 100,000,000。

| 请求 | 内容 |
| --- | --- |
| `POST /api/terms/parse` | 输入 `message`，得到草稿和不支持项 |
| `POST /api/terms/preview` | 提交 [样板 JSON](../demo/terms_monthly_ko.json)，得到预览编号、行情和实际日程 |
| `POST /api/valuations` | 提交 `{"preview_id":"…"}`，返回已保存结果，重复提交返回原结果 |
| `GET /api/valuations` | 本账号最近 30 次估值 |
| `GET /api/valuations/{id}` | 读取本账号估值与同一份快照 |
| `GET /api/valuations/{id}/report` | 导出本账号估值 PDF |
| `POST /api/valuations/{id}/explain` | 可选 AI 解释已保存估值的条款与结算机制 |

POST 使用会话中的 CSRF 令牌。预览有效期 15 分钟，已确认结果可以重复查看。前端不传定价所需的利率、波动率或已计算票息，后端从保存的快照读取。发行商报价按确认条款的哈希精确匹配，维护报价口径与有效期。

# 演示与验收

1. 按 README 启动，使用演示账号登录，确认页首显示「离线演示 · 合成行情」。
2. 点击「加载腾讯无敲出样例」，再获取行情和预览。核对参考收盘 HKD 392.20、接货价 HKD 333.37、最终观察 2027-02-02。确认后，年化估算约 6.59%，持有至到期约 1.66%。
3. 点击「加载每月敲出样例」。敲出价为 HKD 411.81，观察日为 2026-12-02、2027-01-04、2027-02-02。确认后查看约 7.62% 的估算年化票息、参数区间、模拟误差及五种结算情景。预期数值见 [expected_results.json](../demo/expected_results.json)。
4. 切换微软，使用 85% 接货价、面值 USD 100,000。检查美元币种、纳斯达克日历、三个月收盘图和 PDF。通过历史记录打开刚刚保存的结果，核对估值编号一致。
5. 运行 `uv run --locked pytest`。测试覆盖固定人工路径、临界价格、无敲出解析值、行情缺行、API 权限和条款确认。

样板的利率与股息使用固定演示假设。早期版本的 6.57% 用 0.25 年，与本版 92/365 的口径略有差异。每月敲出模型的模拟误差与波动率敏感性区间分开展示。

## 人工路径

参见 [payoff_cases.json](../demo/payoff_cases.json)。固定测试票息 6% 年化，面值 HKD 100,000。第一月敲出票息 HKD 493.15，第二月敲出票息 HKD 1,035.62，持有到期票息 HKD 1,512.33。最终股价为 HKD 300 的到期接货案例，股票等值 HKD 89,990.10。

## 联网演示

参照 [数据配置](data.md) 安装 OpenBB 适配器并配置已核准的假设文件。另开内部账号演示实际行情，页面会标出数据来源与估值日期。对客上线前切换到公司授权行情接口，并使用同样的条款与测试套件验证。

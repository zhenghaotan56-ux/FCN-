# 首版定价模型

估值目标是平价发行。以单位面值表示，令 `R` 为到期或提前终止的本金等值，令 `A` 为每条路径按 100% 年化票息产生的折现票息。公平年化票息为 `(1 − E[PV(R)]) / E[A]`。

无敲出时，本金等值为 `min(1, S_T / K)`。首版以 Black–Scholes 欧式看跌期权计算本金短缺，再用 ACT/365F 及支付日折现反求票息。月度敲出时，按实际观察间隔模拟风险中性 GBM。首次敲出时返还面值，计息停止，其他路径按最终股价计算本金等值。模型一次求出本金和票息年金，直接反求年化票息。

行情收益率使用最近 61 个完整交易日的复权收盘价，60 笔对数收益率样本标准差乘以 √252。平坦连续利率和股息率来自同估值日的已配置假设。首版使用历史波动率估计，给出相对上下调整 20% 的参数敏感区间。该区间与统计误差分别展示。模拟固定种子、10 万条反向配对路径，年化票息标准误按反向配对后的现金流残差估计。

所有路径按同币种、确定性平坦利率折现。估值中的股票交割采用最终观察价的等值现金流。报价结果受股息、隐含波动率偏斜、资金成本、发行商信用和费用影响。计划中的独立定价与发行商条款校验应在客户试点之前完成。
